## ✨ Visão geral

A API concentra os fluxos administrativos do FIXA e fornece os contratos consumidos pela aplicação web para pessoas, instituições, unidades, eventos e indicadores.

## 🚀 Funcionalidades

- Autenticação, renovação e encerramento de sessão
- Alteração e recuperação de senha
- Gestão de instituições, unidades e usuários
- Gestão de turnos, aptidões e locais
- Gestão de eventos
- Consulta e atualização de perfil
- Gestão da foto de perfil
- Disponibilização das informações do dashboard
- Controle de acesso por perfil
- Validação, health check e documentação OpenAPI

## 🧰 Tecnologias

| Área | Tecnologias |
| --- | --- |
| **Backend** | Java e Spring Boot |
| **APIs** | Spring Web MVC |
| **Segurança** | Spring Security, OAuth2 e JWT |
| **Persistência** | Spring Data JPA e PostgreSQL |
| **Apoio** | Redis, SMTP e Thymeleaf |
| **Build** | Maven e Docker |
